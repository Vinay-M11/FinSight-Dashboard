# FinSight-Dashboard

1. Project Title  
FinSight – Interactive Finance Analytics & Transaction Performance Dashboard

2. Short Description / Purpose  
This is an interactive Power BI dashboard designed to analyze financial transactions, customer behavior, transaction performance, fees, and taxes across different customer segments, transaction categories, and geographical regions. It provides a centralized view of financial KPIs, monthly transaction trends, transaction statuses, and customer demographics to help management identify performance patterns and make data-driven financial and operational decisions.

3. Tech Stack  
Power BI Desktop: Dashboard development, interactive data visualization, and report design.
DAX (Data Analysis Expressions): Suitable for KPI calculations, aggregations, and Year-over-Year (YoY) performance analysis.
Power Query: Suitable for data cleaning, transformation, and preparation before analysis.
Data Modeling: Organizing transaction and analytical fields to support consistent calculations and interactive filtering.
Power BI Visualizations: KPI cards, area charts, donut charts, bar charts, matrix/table visuals, and slicers.
Interactive Reporting: Dynamic filtering, cross-visual analysis, page navigation, and transaction-level detail exploration.

4. Features / Highlights
+ Business Problem - Management needs a consolidated way to monitor financial performance across transactions, customer segments, transaction categories, and states. Without an integrated analytical view, identifying monthly fluctuations, tracking successful versus failed transactions, evaluating fees and taxes, and comparing customer contributions can be difficult and time-consuming.

+ Goal of Dashboard - The primary goal is to create an interactive finance analytics solution that brings important financial KPIs and transaction performance indicators into a single reporting environment. The dashboard is designed to help stakeholders monitor transaction growth, compare annual performance, understand customer and regional contributions, and analyze fees and taxes across transaction categories.

+ Walkthrough of Key Visuals:  
➡️ Financial KPI Cards - Provides a quick overview of key financial performance indicators: i.e., Total Amount, Total Transactions, Average Transaction Value, Total Fees, Total Tax. These KPIs help management assess the overall scale and performance of financial activity.  
➡️ Monthly Transaction Trend (Area Chart) - Visualizes transaction amounts across the months of the year. It helps users identify seasonal patterns, monthly peaks, declining activity, and fluctuations in transaction value. Comparing periods can support further investigation into the factors influencing transaction performance.  
➡️ Transaction Status Analysis (Donut Chart) - Breaks down transaction amounts by status: Success, Failed, and Pending. This view helps users understand how financial value is distributed across transaction outcomes and identify potential areas requiring operational attention.  
➡️ Customer Segment Analysis (Horizontal Bar Chart) - Compares transaction amounts across the Retail, Premium, SME, Corporate, and Wealth customer segments. It helps identify segments contributing the most financial activity and supports customer-segment performance comparisons.  
➡️ State-wise Financial Performance (Horizontal Bar Chart) - Compares transaction amounts across states to highlight regions with higher and lower financial activity. This view supports geographical performance evaluation and helps management identify areas for further business analysis.  
➡️ Transaction Type Analysis (Matrix / Table) - Provides a category-level comparison of financial performance across transaction types, including Bill Payment, Card Payment, Deposit, Fee Charge, Interest Credit, Investment, Loan EMI, Refund, Transfer, and Withdrawal.  
➡️ Customer Gender Analysis (Donut Chart) - Compares transaction amount contributions from male and female customers. It provides a demographic view of financial activity and supports further analysis of customer participation.

5. Business Impact and Insights  
FinSight centralizes key financial KPIs to improve visibility into transaction performance, fees, and taxes. Monthly trends and YoY comparisons help identify fluctuations in financial activity. Customer segment, state, and transaction status analysis support performance evaluation and operational improvement. Overall, the dashboard improves reporting efficiency, enables interactive exploration of financial data, and supports data-driven financial and operational decision-making.
